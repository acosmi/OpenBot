## 2. 第一真源落地

- compound 只有一套 root context：`Menu`、`MenuTrigger`、`MenuContent`、`MenuItem`、
  `MenuSeparator`、`MenuSub`、`MenuSubTrigger`；ID 只从 root/sub 的 bounded DOM token 派生；
- trigger 是 native button，显式 `aria-haspopup=menu`、`aria-expanded`、`aria-controls`；root/sub
  content 是命名 `role=menu`，item 是 `role=menuitem tabindex=-1`；disabled 同时走 native
  disabled、`aria-disabled=true` 与 `data-state~=disabled`；
- 前端第一真源 §6.1 的 open/disabled 状态不再由视觉选择器猜 ARIA：closed helper 只产
  `open`、`disabled`、`open disabled` 三种非默认 token，CSS 读 `data-state`；
- trigger click/Enter/Space/ArrowDown 开首项，ArrowUp 开末项；根/子菜单 ↑↓ wrap、Home/End、
  disabled skip；typeahead 保存最多 500ms 的多字符前缀；
- submenu 只允许一层。Right/Enter/Space 打开并进首项；Left/Escape 只关闭当前层并回父项。
  子 content 与父 trigger 对已处理键都 stop propagation，避免一次 Escape 同时关闭两层；
- item callback 只暴露 unit，不泄漏 MouseEvent/KeyboardEvent；Enter/Space/click 都走同一选择→
  root close→return trigger 路径，disabled 在 callback 前拒绝；
- root Escape、trigger toggle、透明 outside dismiss 都走同一 idempotent close。Tab 不先
  `preventDefault`：先保留浏览器原生页序；仅当引擎仍把焦点留在即将隐藏的 menu/body 时，
  forward 恢复到 trigger 后一项、backward 恢复到 trigger，保证 §9.2“焦点永不落 body”。
