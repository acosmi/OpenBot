# Project logo concept — Open Keystone

This is a name-agnostic identity concept for the repository. It intentionally
contains no `OpenBot` wordmark: the repository rules reserve the external
product name, logo, and application icon until product-identity and trademark
review are complete.

## Idea

- The open octagonal core represents a dependable Rust execution boundary.
- The top opening represents extensibility and an open tool ecosystem.
- The detached keystone represents an explicit control point and subtly reads
  as a person, reflecting human-governed AI collaboration.

## Usage

- Prefer `logo-mark.svg`; the master is fixed to the light-theme `#111111`.
- Use `#111111` on light surfaces. When making a dark-surface export, recolor
  both solid shapes uniformly to `#F4F4F5` and change nothing else.
- Keep clear space around the mark at least half the keystone's width.
- Minimum recommended display size: 16 px.
- Do not rotate, stretch, add gradients, shadows, outlines, or extra colors.

## Files

- `logo-mark.svg`: exact two-shape vector master.
- `logo-mark-1024.png`: transparent raster export from the vector master.
- `logo-theme-preview.png`: approved light/dark neutral-color preview.
- `logo-mark-concept-source.png`: transparent ImageGen concept used as the
  visual starting point for the exact vector reconstruction.
