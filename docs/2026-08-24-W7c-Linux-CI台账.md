## 4. 证据边界

默认 CI 的 `cargo test --workspace` 不执行需要数据库凭据的 ignored 测试，故不能替代本机
PostgreSQL 17/SCRAM **521/0/0**。它也没有启动 gVisor；runsc 必须在 G5 的真实 Supervisor 与
可控 Linux daemon 同批验收。G2 当前仍受独立 SAML/XSW/整体安全外审、Server KMS/HSM、
Windows 原生构建和真实 G4 executor 阻塞，整关保持未勾。

§24 Go/No-Go 只限制勾关与发布晋级。v3 §19.2 明确 Computer、GUI、Agent 为并行实施线；
因此上述未完成项不再被用作停止 G3–G7 代码实施的理由。
