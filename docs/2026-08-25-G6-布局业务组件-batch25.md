## 3. 生产实现

### 3.1 PageShell

- `PageWidth` 闭集只允许 content/table/chat，分别消费
  `--size-content-max` / `--size-content-max-table` / `--size-content-max-chat`；
- `PageTopbar` 固定44px token；`PageHeader` 是唯一 h1，`PageSection` 用 stable h2 ID；
- `PageBackLink` 只接 bounded same-origin absolute path；非同源输入在构造时拒绝；
- `PageRows/PageEmpty` 固定配置页的行组与句子级空态；
- 现有 production `ApprovalPage` 已从手写 `.ob-page` 改为真实 `PageShell`接线。

### 3.2 DetailPanel

- caller 持有 URL/search 投影 `open`；内核持有 `present + phase + generation`，状态只有
  `opening/open/closing/closed`；
- 360px、enter/exit 240/160ms、easing 直接使用 build.rs 生成的 Rust token；
- 支持 WAAPI `width + flexBasis + opacity`尺寸联动；API 不可用或建立失败时，
  等待同 token 的 CSS transition；`prefers-reduced-motion: reduce` 下 duration=0；
- 关闭动画完成后才卸载 detail 子树；Enter/Space 显式 `preventDefault`，与 click 共用
  exactly-once close；每次都返焦 caller 提供的 stable opener ID；
- `data-animation-path` / `data-animation-duration-ms` 只暴露非敏感验收状态，不记录用户数据。

### 3.3 RowMark / Stagger

- `RowMark` 是36×36中性 vendor tile，只消费 token surface/currentColor，不用语义色当背景；
- `StaggerItem` 只用静态 class + `data-stagger=0..8`；大于8的索引固定cap=8；
- CSS 只消费 `--motion-stagger-step=30ms`与 `ob-list-stagger`，全局 reduced-motion 闸门不设例外。

## 4. 实测中发现并修复的问题

1. 关闭时若直接 hidden，焦点会落到 body；改为 stable return-focus ID。
2. 只依赖按钮的浏览器隐式 click，本机 Enter/Space 不能稳定触发；改为显式键位处理且防双触发。
3. 精确1024px视口下，经典滚动条让 client width=1009px，固定两列 gallery 会在页面无横滚时
   静默裁掉 detail。改为用 `sidebar + detail` 两个 token 的 `auto-fit/minmax`，没有新增断点。
4. 内嵌浏览器的外部评估不暴露 `Element.animate`，但应用内 WASM 实测路径为
   `waapi`、exit/enter token 为160/240ms。验收环境将 `Animation.finished` 快进至终态，
   因此本批只声明路径/token/终态，不冒充测得中间帧时间曲线。
