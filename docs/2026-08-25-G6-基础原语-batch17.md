## 2. 第一性原理裁决

### 2.1 activation 不泄漏鼠标事件

Button 与 Item Button 的业务 callback 输入是 unit，不把 `MouseEvent` 送到 feature/use case。
组件显式处理 Enter/Space 并 `preventDefault`，pointer/keyboard 只汇成一次 activation；disabled/
loading 在 callback 前拒绝。真实 Chromium 每键恰增 1，排除了“keydown + native click 双触发”。

### 2.2 Field context 必须隔离 sibling

直接 `provide_context` 会让同一 reactive owner 下后创建的 Field 覆盖前一个，standalone Input
也可能错误继承最后一组 ID。实现改用 Leptos scoped `Provider`，每个 Field 独立拥有
control/description/error ID、invalid/disabled signals；Input/Textarea/Switch 只读取祖先 Field。
非法/可拆 ARIA token 的 ID 在第一方代码边界当场失败。

### 2.3 Item 不接受自由 URL 或自由 tag

ItemAction 只有 same-origin absolute path Link 与 unit-callback Button。`//host`、scheme URL、
控制字符、反斜杠、超长值被拒；没有 renderer 传自由 HTML tag 的入口。selected 自动附
`aria-hidden` check，selected 本身只改文字/图标，只有 hover 才使用 neutral surface。

### 2.4 Textarea 十行上限是 token，不靠新 CSS 算术

第一版把 `calc(var(--line-height) * 10 + …)` 的十行公式留在手写 CSS；这会让“十行上限”
脱离 token 真源，并无必要地把 typed arithmetic 支持当三引擎前提。改为 `tokens.toml` 单源
`--size-textarea-max:218px`（10×20 + padding16 + border2）；Rust/WASM 仍按 scrollHeight
自动增高，CSS token 跨引擎截顶。

### 2.5 设计画廊只能编译期存在

`design-gallery` feature 才编译 `/_design` 与全部状态样本；production 默认 feature 关闭。
`design-lint` 只允许 file-level/近邻 cfg 守住的 route，`bundle-budget` 又直接扫描 production
WASM，出现 `_design` 字节即红。本机 production/design-gallery 两 bundle 分别 `_design=0/1`。
test-only fixture 只托管真实 production primitive/WASM，不承担后端真实性或 golden 完成证据。
