## 验收

1. 从全新隔离 PG/schema/session 启动 production adapter/Server listener，分别捕获 SSE 与 WS 的实际 frame 序列；中途主动切断真实连接。
2. 重连实际携 last cursor；比较无中断控制组与故障组 canonical semantic identity/order，跨 replay/live 边界无丢失/重复。包含在断开窗口内追加事件、边界重复帧、旧/错 scope cursor。
3. 401、429/Retry-After、超时、cancel/terminal race 四组真实 fault injection，固定计时可复算；最终 terminal 恰一。retry、unknown commit、call-time authority沿既有契约，不能为测试创建隐式 allow 或自动重做有副作用请求。
4. 记录谁断开、实际请求 method/path（无 token）、安全 header 名、cursor、frame ID/sequence 与归一化期望；凡 synthetic peer/fault 明确标记，不能叫官方 vendor 录制。
5. 取消后 pending task、socket、listener 与 PG 临时库清理；跨 actor/tenant/channel/run 的数据 canary 0，replay 不突破当前权限或 resurrect 已清理 reasoning/projection。

7. 两个新 test target、相关现有 Server/Infra 定向回归、对应 Clippy、fmt、diff-check。PG ignored 必须实际启用，逐条记录 passed/failed/ignored 和环境。
