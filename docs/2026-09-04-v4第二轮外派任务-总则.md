## 交付合同

只提交允许范围，形成基线后恰一个候选 commit，附以下内容：

1. 标签、分支、绝对工作树路径、基线和候选完整 SHA；`git rev-list --count <base>..<candidate>`。
2. `git diff --name-status <base>..<candidate>`、`git diff --check`、干净 `git status --short`；不把别人的未提交文件加入。
3. 改动原因、真实行为、测试命令、退出码与 passed/failed/ignored；原始输出位置、必要的消毒后机器证据及复算命令。
4. 新资产/依赖的官方固定来源、许可、字节与哈希，以及中央 NOTICE/SPDX 所需精确增补；不导入原始安装包、私有源码或 secrets。
5. 已验证、未验证和真实阻塞分开；没有平台/凭据就如实交环境或证据缺口，不制造通过。

主控亲读代码、追核一手来源、独立复算并重跑，再按实际证据集成和更新 T-ID。候选测试通过不等于完整 Alpha、G0–G8 或 v4 完成。
