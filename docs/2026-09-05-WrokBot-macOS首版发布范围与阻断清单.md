# Wrok Bot macOS 首版发布范围与阻断清单

日期：2026-09-05。用户最新裁决：**首版先发布 macOS**。本文件落实 v4 §0.5、§24.2、
§28.1 R204 的发布顺序，不替代架构第一真源，也不改变完整v4的最终完成条件。

## 首版范围

| 项目 | 当前确定范围 |
|---|---|
| 产品名称 | Wrok Bot；底层名称继续按兼容迁移完成 |
| 首发平台 | macOS。安装包的CPU架构、最低系统版本与实际真机覆盖必须明示；arm64证据不能外推Intel |
| 交付形态 | 可安装的本机产品，面向本人及少量受邀用户，每人独立本地实例 |
| 三条必需故事 | 工作台与AI工具；浏览器操作及接管；原生电脑操作及停止 |
| 已有启动证据 | `wrok-bot-server --local` + 独立PG的开发/联调路径；不等于macOS安装包已经完成 |
| 首发退出条件 | macOS实际启用路径逐项通过A0–A7，已知P0/P1及安全/数据不变量不得豁免 |
| 后续平台 | Windows独立修复、验收后发布；Linux/runsc与公开多用户Server按后续范围推进 |
| 全量目标 | 保留v4全部平台、能力、T-ID、fixture、G0–G8及§25 DoD；首版发布不标记全量complete |

首版不再按“macOS与Windows一起上线”或“哪个平台先通过哪个先发”的开放顺序执行，
而是明确由macOS首发。Windows E2继续交同事原生运行、回传后验收，既不提前合并，也不阻塞
macOS首版的独立准入。Windows/Linux发现的共享代码缺陷若实际影响macOS已启用路径，仍须修复。

此前5–7个工作日是macOS受控内测的滚动估算，不是已经验证的发布日期；此前2–3周的跨平台首版
估算不再作为当前首发范围。以本表剩余阻断项与实际验收更新排期，不以时间到期代替发布证据。

## 当前阻断项

| 阻断项 | 已有事实 | macOS首版退出证据 |
|---|---|---|
| 安装与本机生命周期 | 本机Server/PG启动与重启已测；Desktop assembly和sidecar组件已有实现 | 以Wrok Bot身份在干净macOS安装、启动、退出、重启；实际包、架构、版本、来源与诊断可核验 |
| 浏览器与Screen生产接线 | Engine、ScreenHub、控制/票据与出口网关已有分项证据 | 唯一ComputerManager→Engine→网关→Screen贯通；明确target、当前授权、接管/Stop与错误恢复 |
| 原生电脑控制 | 来源评估与底层移植证据不等于本产品真实动作 | 本产品OS权限提示、输入互斥、动作receipt、实际结果变化、取消与越权负向通过 |
| 真实AI工具故事 | 对话持久化/Vault/模拟provider、技能授权快照已测 | 首版启用的真实provider完成工具、审批/拒绝、取消/预算与恢复；模拟器不替代live |
| 发布安全与身份 | macOS helper-loader加固仍有独立在制差量 | 拟交付Engine/宿主身份、权限、来源与实际隔离通过；不把诊断签名例外当生产证据 |
| 数据恢复与升级 | 原有PG/迁移能力不等于首版恢复演练 | 新数据backup→restore→checksum及升级失败恢复实跑 |
| GUI完整核心旅程 | 独立前端窗口实施中，后端提供稳定契约 | macOS实际三条故事、失败状态、中英文、键盘/焦点及必要可访问性验收 |

本窗口只实施后端，前端设计和实现交由前端窗口；后端发布准确DTO、权限、状态和验收接口。
企业SSO未支持状态、未连接Computer等必须真实投影，不能以空数据或成功占位隐藏能力缺口。
