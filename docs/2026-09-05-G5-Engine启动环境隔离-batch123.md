## 发现与修复

在继续 Engine proxy/navigation 接线时，亲读发现两个平台路径仍复制父进程环境：Unix 只移除四个
Electron/Node 变量；Windows 枚举 `std::env::vars_os()`，只过滤同样四项。
这会把与 Electron 无关的 provider/DB 配置、凭据或 loader/key-log 设置带给引擎，不能直接进入真实网页执行。

本轮以无秘密的 synthetic canary 复现：macOS Browser/Component 两角色的 main 与 renderer 四处均为
`inherited=true`；读取同一 canary 的父进程正向对照成立。改为封闭启动环境后，四处均为false。
只检查本任务拥有的进程；`ps`返回内容只留测试内存，外层仅接受两种固定布尔文本，不输出真实变量、值或argv。

Unix `append_engine_args` 先 `env_clear()`，再固定五个键：HOME指向scope profile，TMPDIR/TEMP/TMP指向
scope temp，PATH只含`/usr/bin:/bin`，cwd同样固定profile。Linux runsc probe在此基础上只追加既有固定
`DISPLAY=:99`。这是配置子进程的home，没有修改主控/宿主HOME或任何全局环境。

Windows 删除环境枚举，唯一unsafe边界用只读 `GetSystemWindowsDirectoryW`取得真实OS目录；不相信
父环境中的SystemRoot/PATH。纯Rust builder构造固定九键、排序、UTF-16双NUL结尾、总量≤32767 units：

| 来源 | 键 |
|---|---|
| scope profile及其AppData子目录 | HOME、USERPROFILE、APPDATA、LOCALAPPDATA |
| scope temp | TEMP、TMP |
| OS实际Windows目录及System32 | PATH、SystemRoot、WINDIR |

路径必须有界、absolute、无NUL/换行，PATH源不允许分号注入；没有父PATH、驱动器当前目录、任意自定义键或
“失败后继承”分支。profile内的AppData目录由authority侧创建。新增Windows SystemInformation feature
仅在Windows边界crate声明，未新增package、unsafe crate、Root Cargo依赖或Node代码；SECURITY.md同步该只读API。

环境继承与 `env_clear` 语义见 [Rust Command](https://doc.rust-lang.org/std/process/struct.Command.html#method.env_clear)，
Windows自定义环境块见 [Microsoft进程环境说明](https://learn.microsoft.com/en-us/windows/win32/procthread/changing-environment-variables)。
OS目录读取采用 [GetSystemWindowsDirectoryW](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/nf-sysinfoapi-getsystemwindowsdirectoryw)，
避免Terminal Services的每用户兼容目录和父环境别名成为新的来源。

## 边界与后续

只修环境继承，不宣称补齐所有进程权限：

- Windows真实环境块/系统目录API运行仍待真机；Known Folder API与文件/网络访问权限并不由HOME变量改变。
- Linux无runsc/Xvfb运行证据，不能用target check替代。
- macOS现有主进程SBPL的读取范围、localhost/UDS范围与helper exec边界仍需独立compromise验证和收紧；
  `env_clear`不能替代文件隔离或阻止已被攻破的进程自行构造新的child环境。
- Engine wire/shim仍epoch4，未启用真实网页；proxy/navigation、production scope owner、tenant policy和
  namespace接线继续，完整G5/G7/Alpha/v4不勾。
- E远程准备提交仍`de8d0ecc`、代码base R196；本地环境修复没有覆盖同事分支，最终Windows验收须包含
  这项后续delta。主控没有因此取得其他分支的上传/合并或Actions授权。
