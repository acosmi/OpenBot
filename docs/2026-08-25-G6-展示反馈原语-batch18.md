## 2. 构造性边界

### 2.1 Message/Bubble 不承载 markdown 或业务状态

Message compound 落 article/group/avatar/content/header/footer，align 只有 start/end；每个 article
必须有非空 accessible name。Bubble 只有 User/Assistant 两种纯展示外框，无独立 role、无
border、无彩色 surface；forced hover 只切 neutral popover。markdown/streaming 仍由后续
MessageScroller/Transcript 负责，不能借 Bubble 完成冒充。

### 2.2 Kbd 的 Primary 不是硬编码 macOS

Kbd modifier 闭集 Primary/Control/Alt/Shift，key 闭集 Enter/Escape/Slash/ASCII 字符。WASM
读取宿主 platform：Apple 映射 ⌘/⌥/⇧，其它平台映射 Ctrl/Alt/Shift+；纯函数单测同时钉两腿，
特殊键 accessible name 走 i18n。任意标点不能从 Character 分支进入。

### 2.3 Avatar 不请求远程图片

image 只接 bounded same-origin absolute path，外层 role=img/name 宣读一次、内层 img `alt=""`；
remote/scheme-relative/control/backslash 负向拒绝。无图时：CJK 首字，英文首/末词 initials。
palette=`u32::from_be_bytes(SHA-256(principal_id)[0..4]) % 8`，颜色在 tokens.toml 亮/暗各八值；
16 组 fg 对比全部 ≥4.5，不靠运行时随机。

### 2.4 Toast 的旧 timer 不能关闭新状态

Toast 是 `role=status`/`aria-live=polite`，固定 5000ms，可手动关闭。每次 visible false→true
推进 generation；timeout 只在 generation 未变时关闭。ToastViewport 只提供有界 fixed stack，
Toast 本体仍可在 design gallery 内联。compile preview 强制 open，不等待墙钟。

### 2.5 Tooltip 同时保留 hover 与 focus

TooltipTrigger 只允许 bounded same-origin Link 或 unit Button；tooltip ID 是 closed DOM token。
hover/focus 各有 signal，共用 400ms generation：鼠标离开但焦点仍在时不关，blur 但仍 hover
也不关；两者都离开才取消/关闭。Escape 无条件立即关闭并移除 `aria-describedby`。preview open
是 compile-gallery 状态，production 不强制。
