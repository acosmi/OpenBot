## 3. 为什么不把 server-side-tools 5 条一起改 done

固定上游用例实际启动 MCP HTTP server，并同时行使 Bot grant、vendor input schema、
policy refusal 与 `mcp.call_succeeded/rejected` audit。v3 §8.1 又明确真实 MCP executor 属 G4，
§9.3 要求 catalog generation 与 stale-grant 事务状态。当前 0015 schema 没有这些状态；
因此 fake HTTP、test-only executor 或一个不持久 generation 的 adapter 都无法构成证据。

解除条件是一次同批真竖切：RMCP 3.1.4 + MCP 2026-07-28/compatible negotiation +
唯一 safe dialer Streamable HTTP + catalog/stale-grant expand-only migration + 权威 schema/grant +
`ApplicationService` decision/attempt/capability + MCP audit。五条在那时逐条改 done，本批不预支。
