## 2. Policy 写面

- `ActionPolicyDocument` 是 wasm-safe DTO，不把编译 CEL/内部版本暴露给 renderer；
- Get/Set 是封闭 `AppCommand`，application 统一 admin gate、DTO↔domain 穷尽映射和权威 actor；
- `PolicyStore` 实现唯一 port；PG 真腿证明 `updated_by` 来自 actor id、DB 行与预编译 Arc 同批更新；
- GET 未配置返回 `policy:null`，保留 first-setup/default-deny，不伪造上游隐式 allow-all；
- PUT 在解析 body 前要求 fresh live admin + trusted Origin；缺 Origin/角色不足均零 port 副作用；
- 路由只声明精确 `/api/computers/policy`。`/policy/status` 与 `/some-bot/status` 当前均 plain 404，
  证明没有 Hono wildcard exemption；这不冒充未来 G4/G5 Bot status/access 已实现。
